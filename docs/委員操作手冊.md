# 委員操作手冊

你只需要用 **Google 試算表** 和 **Google Drive**。不需要懂程式，也不用記編號。

試算表上方有一個選單「**管委會網站**」。如果沒看到，請重新整理頁面。

## 新增或修改資料

1. 到對應的分頁（議題、待辦、決議、會議、管理辦法、公告），在最下面的空白列填寫，或直接修改既有的列。
2. 標題為淺藍底的欄位是必填（滑鼠移到標題上可看說明）。
3. 下拉選單的欄位請從選單選擇。「相關議題」「來源會議」選單會顯示「編號＋標題」。
4. **灰色欄位不用填**：編號、建立日期、更新日期會自動產生。請不要修改，修改時會跳出警告。
5. 勾選「**公開**」的資料才會出現在網站上。

### 敏感議題

財務或涉及個人的議題，請把「公開範圍」設為「**內容遮蔽**」。網站只會顯示標題、分類與狀態，內容會顯示為「[財務內容已遮蔽]」。這個議題的待辦與決議預設也會一起遮蔽。

### 優先程度

未勾選「優先已確認」時，網站會註明「目前為初始化建議，尚非正式決議」。

## 發布到網站

點選單「**管委會網站 → 發布網站**」。

- 看到「✓ 資料檢查通過」後，資料就送出了。網站會在**隔天清晨約 4 點**自動更新（如果技術維護者有開啟立即更新，約 3–5 分鐘就會更新，對話框會告訴你是哪一種）。
- 看到「✗ 有 N 個問題需要修正」時，網站**不會**更新，也不會壞掉，會繼續顯示上一版。請依訊息修正後再發布一次。

錯誤訊息的格式如下：

> 待辦 第 17 列（ACT-20260922-05）：「相關議題」= ISS-0099，找不到對應議題

它的意思是：到「待辦」分頁第 17 列，把「相關議題」改成存在的議題。

只想先檢查、不發布時，請用「**檢查資料**」。

就算忘了按發布，系統每天清晨也會自動把試算表的內容更新到網站。急著更新時，請聯絡技術維護者到 GitHub 手動重建。

## 會議紀錄與管理辦法全文

1. 把 Google 文件或 Word 檔（.docx）放在你的 Google Drive。檔案**不需要**設為公開。
2. 複製檔案連結，貼到該列的「紀錄文件」（會議）或「內文文件」（管理辦法）。
3. **點選那一列**，再點「管委會網站 → 預覽並核准文件」。
4. 對話框會顯示網站上將出現的全文，自動遮蔽的地方以黃色標示。請**從頭到尾看一遍**。
5. 確認沒問題後按「核准」，再按「發布網站」。

注意事項：

- 文件裡的圖片不會放到網站上。
- 核准後又修改了文件，網站仍會顯示上次核准的版本，「文件核准狀態」欄會出現 ⚠。請重新預覽並核准。
- 對話框顯示「仍有疑似個資未能自動遮蔽」時無法核准。請修改原始文件，或把人名加到「遮蔽詞庫」。
- 想讓大家下載原始檔時，才需要填「公開檔案連結」，而且該檔案必須是**已經確認可以公開**的版本。原始檔不會經過遮蔽。

## 個資保護：遮蔽詞庫

電話、Email、身分證、車牌、帳號、戶別、金額會**自動**遮蔽。

**人名無法自動辨識。** 請把需要遮蔽的人名，包括住戶、廠商人員、物業人員，加到「**遮蔽詞庫**」分頁，每列一個：

| 要遮蔽的詞 | 遮蔽為 | 備註 |
|---|---|---|
| 王小明 |  | 住戶 |
| 王先生 |  | 同上，另一種稱呼 |
| 某某物業陳經理 | [物業人員] |  |

- 「遮蔽為」空白時，會顯示「[姓名已遮蔽]」。
- 這個分頁**永遠不會**出現在網站上。

如果物業服務中心電話這類資訊應該公開，卻被遮蔽了，請把它寫到「網站設定 → 不遮蔽的公開資訊」。

## 其他設定

- **選項**分頁：新增議題分類或負責單位，新增後下拉選單就可以選用。
- **網站設定**分頁：網站名稱、首頁文字、頂部提示、頁尾附註等，改「內容」欄即可。
- **發布紀錄**分頁：每次檢查與發布的結果。遇到問題時，把這裡的訊息提供給技術維護者。

## 出問題時

| 狀況 | 做法 |
|---|---|
| 下拉選單不見了、欄位被刪了 | 「管委會網站 → 初始化／修復試算表」（不會刪除資料） |
| 誤刪、誤改資料 | 試算表「檔案 → 版本記錄 → 查看版本記錄」，還原到之前的版本 |
| 選單沒出現 | 重新整理頁面；還是沒有的話，請聯絡技術維護者 |
| 發布失敗、但看不懂訊息 | 把「發布紀錄」最上面一列的說明提供給技術維護者 |

請不要做以下事情：

- 把試算表分享為「知道連結的任何人」。試算表必須保持私有。
- 刪除隱藏的欄位或分頁（`_internal_id`、`_refs`）。
- 手動修改灰色欄位。
